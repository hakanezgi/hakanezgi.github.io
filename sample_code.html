Part 1¶

Question

  1. Implement three different planning agents for solving the tower of Hanoi:
    • Agent 0 plans h steps ahead, and then chooses the plan for which the state after h steps is most similar to the final goal (where similarity is measured by the number of disks that are on the same peg in both states).
    • Agent 1 first sets the subgoal to move the largest misplaced disk to its target location and then plans h steps ahead to try to find a way how to accomplish that subgoal. The agent then executes the best plan it could find. Once the subgoal is accomplished the agent repeats its cycle of goal-setting, planning, and plan execution until all disks are in their target locations.
    • Agent 2 is identical to Agent 1 except that it sets its subgoal by resolving to move a randomly selected disk to its target location. 
  2. Simulate how well the three agents perform at transforming one randomly chosen initial arrangement of the disks into a) a tower in a random location, or b) another randomly chosen configuration. Repeat this simulation for different values of h.
  3. For each agent plot its average performance as a function of its planning horizon h and interpret your findings.

---

In this first part of the assignment, I implement and compare the performances of three agents for solving the well-known Tower of Hanoi puzzle.

This puzzle consists of several disks of different sizes and several pegs. The disks are initially distributed to the pegs randomly, forming a random state. They can be moved to other pegs as well. However, there is a constraint: a larger disk can never be placed on top of a smaller disk at any time. The main goal is to move all the disks, in correct order (largest one at the bottom and gradually decreasing in size), into one peg to form a tower.

In the question text, three agents are described:

Agent 0: Given an initial state, it calculates all possible moves after h disks are moved. It picks the combination that resembles the goal the most.

Agent 1: Similar to Agent 0, it calculates all possible moves after h disks are moved from the initial state. But its selection algorithm is different. First, it compares the initial state with the goal and detects all misplaced disks. Among all the misplaced disks, it sets moving the largest one to its goal peg as a subgoal. Accordingly, its selection algorithm picks the state that resembles this subgoal the most. Unlike Agent 0, it doesn't stop at this point. From the current state, it reiterates all the steps (to calculate all possible moves after h disks are moved, detect the misplaced disks, set moving the largest disk to its goal peg as subgoal, and finally pick the state that resembles this subgoal the most) until all disks are moved to their respective goal pegs.

Agent 2: Agent 2 executes similar to Agent 1. The only difference is about setting the subgoal. After detecting all misplaced disks, it randomly selects a disk to move to its respective goal peg as the subgoal. Similar to Agent 1, it reiterates its algorithm until all disks are moved to their goal pegs.

When I first read about the algorithms of the agents, intuitively I guessed the following: Agent 0 performs well under complete randomness, but may get stuck if smaller disks are already at the correct peg while larger ones are not. Also, its performance will be highly dependent to the h-value. Moving the largest misplaced item to the goal first feels like a wise move, hence, in my opinion the Agent 1 will perform best. Finally, the performance of Agent 2 will approximate to the performance of Agent 1. Randomness may work well for small problem sets. But, as the problem gets larger with more pegs and especially more disks, it will struggle to find the correct solution.

However, intuition has no place in science. We need a systematic methodology to evaluate the performances. In the following subsections, first I present the code. Then, I demonstrate how the agents work with a sample run (toy example). Finally, I run the simulations on four different topologies and present the results with plots and statistical analysis.

def randomTower():
  '''
  creates a tower including all disks at a randomly selected peg
  @return the tower
  '''

  tower = []

  # select a random peg as the goal
  pegID = random.randint(0, numberOfPegs - 1)

  # create the tower
  for i in range(numberOfPegs):
    if i == pegID:
      tower.append([i for i in range(numberOfDisks, 0, -1)])
    else:
      tower.append([])

  return tower


def printHanoi(state):
  '''
  prints a state in a graphical-like output
  @param state: the state to be represented
  '''
  
  temp = copy.deepcopy(state)

  # create the representation of an empty row in a peg 
  emptyRow = ' ' * (numberOfDisks-1) + '|' + ' ' * numberOfDisks


  for i in range(numberOfDisks+1,0,-1):
    
    row = ''
    # iterate over each peg and add its information to the row
    for j in range(numberOfPegs):
      # if the peg does not have a disk at this level, append an empty row 
      if len(temp[j]) < i:
        row += emptyRow
      else:
        # print a disk shape according to its size
        disk = temp[j].pop()
        for k in range(numberOfDisks-disk):
          row += ' '
        for k in range(disk):
          row += '- '
        for k in range(numberOfDisks-disk):
          row += ' '  
        
    print(row)


def calculateSimilarity(goal, state):
  '''
  calculates the similarity between a goal and a state. the similarity is the 
  number of disks that are at the same peg in both goal and state.
  @param goal: the goal we are trying to reach
  @param state: the current state
  @return the similarity value
  '''
  similarity = 0
  
  # iterate over each peg in the goal
  for index, goalPeg in enumerate(goal):
    # for each disk in this peg, check whether the current state contains it
    # if so, increase similarity by one 
    for g in goalPeg:
      if g in state[index]:
        similarity+=1

  return similarity


def randomState():
  '''
  creates a random state. it is used for initializing the problem.
  @return the created state
  '''
  # initially create the pegs empty
  state = [[] for i in range(numberOfPegs)]

  # then randomly locate the disks
  for i in range(numberOfDisks, 0, -1):
    state[random.randint(0, numberOfPegs - 1)].append(i)

  return state


def calculateOneStep(state):
  '''
  calculates all possible states that can be achieved with a single step from
  the provided state.
  @param state: the current state
  @return all possible states
  '''

  allPossibleSteps = []
  
  # iterate over each peg
  for i in range(numberOfPegs):
    # if the peg contains disks
    if state[i]:
      # iterate over each peg
      for j in range(numberOfPegs):
        # do not compare with the same peg
        if i == j:
          continue

        # if this peg's disk is larger than other peg's disk
        # then skip
        if state[j] and state[i][-1] > state[j][-1]:
          continue

        # otherwise, move the disk to the other peg
        temp = copy.deepcopy(state)
        temp[j].append(temp[i].pop())

        # append the obtained state to the possible steps list
        allPossibleSteps.append(temp)
        
  return allPossibleSteps


def lookHStepsAhead(state, horizon):
  '''
  takes the current state and the h-value as parameters and
  plans h steps into the future. 
  @param state: the current state
  @param horizon: the h-value
  @return all possible states
  '''

  currentIteration = []
  future = []

  # from the current state, calculate one step into the future
  oneStepFurther = calculateOneStep(state)
  # add these states to both current iteration and all possibilities lists 
  for item in oneStepFurther:
    currentIteration.append(item)
    future.append(item)
    
  nextIteration = []

  # do the following until h-steps are complete
  for step in range(horizon-1):
    # process each state in the current iteration separately
    for item in currentIteration:
      # for each state, calculate one step into the future
      oneStepFurther = calculateOneStep(item)
      # add the states in the future into the next iteration's list
      # and all possibilities list
      for newItem in oneStepFurther:
        # no duplicates
        if newItem not in nextIteration:
          nextIteration.append(newItem)

        # no duplicates
        if newItem not in future:
          future.append(newItem)

    # after all the states are processed in the current iteration
    # update current iteration with the contents of the next iteration list
    currentIteration = copy.deepcopy(nextIteration)
    nextIteration = []

  return future


def findMisplacedDisks(goal, state):
  '''
  takes the goal and the current state as parameter 
  finds and returns all misplaced disks in ascending order
  @param goal: the goal
  @param state: the current state
  @return a list of misplaced disks in ascending order
  '''

  misplacedDisks = []

  # iterate over each peg in the goal
  for index, goalPeg in enumerate(goal):
    # for each disk in this peg, check whether the current state contains it
    # if not, append it to the list of misplaced disks
    for g in goalPeg:
      if g not in state[index]:
        misplacedDisks.append(g)
      
  return sorted(misplacedDisks)


def createMisplacedSubgoal(goal, state, largest = True):
  '''
  creates a subgoal.
  @param goal: the goal
  @param state: the current state
  @param largest: a boolean variable to indicate whether we are trying to 
                  locate the largest mismatched disk (True), or a random one (False)
                  as the subgoal
  @return the created subgoal and this subgoal's similarity with the goal
  '''

  # first, find the list of misplaced disks
  misplacedDisks = findMisplacedDisks(goal, state)
  
  # check the 'largest' parameter
  # if it is True, then set the last item (largest) of the misplaced disks as target
  # otherwise, randomly select a misplaced disk as the target
  if largest:
    targetDisk = misplacedDisks[-1]
  else:
    targetDisk = random.choice(misplacedDisks)

  # initially create the subgoal as an empty state
  subgoal = [[] for i in range(numberOfPegs)]

  # create the list of correctly placed disks and append the target into this list
  correctlyPlacedDisks = [i for i in range(1, numberOfDisks+1) if i not in misplacedDisks]
  correctlyPlacedDisks.append(targetDisk)

  # iterate over the pegs of the goal
  # insert all correctly placed disks into the subgoal state
  for index, goalPeg in enumerate(goal):
    for g in goalPeg:
      if g in correctlyPlacedDisks:
        subgoal[index].append(g)

  return subgoal, len(correctlyPlacedDisks)

def runAgent0(mainGoal, initialState, horizon, verbose=False):
  '''
  implementation of the Agent 0.
  @param mainGoal: the main goal (state) that we are trying to reach
  @param initialState: the initial state that the agent will begin its search
  @param horizon: the h-value
  @param verbose: a boolean variable for detailed outputs
  @return the state that Agent 0 selects as the solution, its similarity with
          the main goal, and its execution time
  '''
  
  # start stopwatch - tick tock, tick tock
  start = time.time()

  # first, copy the initial state into current state variable
  currentState = copy.deepcopy(initialState)

  # find all possible states after h-steps
  future = lookHStepsAhead(currentState, horizon)

  selectedStateSimilarity = -1
  selectedNextState = []

  # analyze each possible state separately and find the state having largest
  # similarity value with the main goal
  for item in future:
    similarity = calculateSimilarity(mainGoal, item)
    if similarity > selectedStateSimilarity:
      selectedStateSimilarity = similarity
      selectedNextState = copy.deepcopy(item)

      # if 'verbose' parameter is set to True, print the state
      if verbose:
        print("Possible next state:")
        printHanoi(selectedNextState)
        print()

  # stop stopwatch
  executionTime = time.time() - start

  return selectedNextState, selectedStateSimilarity, executionTime

def runAgent1(mainGoal, initialState, horizon, verbose=False):
  '''
  implementation of the Agent 1.
  @param mainGoal: the main goal (state) that we are trying to reach
  @param initialState: the initial state that the agent will begin its search
  @param horizon: the h-value
  @param verbose: a boolean variable for detailed outputs
  @return the state that Agent 1 selects as the solution, its similarity with
          the main goal, and its execution time
  '''

  # start stopwatch - tick tock, tick tock
  start = time.time()
  
  # first, copy the initial state into current state variable
  currentState = copy.deepcopy(initialState)

  # save the results of the two previous iterations
  # in case the agent cannot achieve the subgoal with
  # the provided h-value and gets stuck
  previousFuture = None 
  previousPreviousFuture = None
  counter = 0

  selectedStateSimilarity = numberOfDisks

  # do the following as long as misplaced disks exist
  while findMisplacedDisks(mainGoal, currentState):

    # create the subgoal to move the LARGEST misplaced disk into its goal peg
    subgoal, subgoalSize = createMisplacedSubgoal(mainGoal, currentState, True)

    # if 'verbose' parameter is set to True, print the current state and subgoal
    if verbose:
      print("Current state:")
      printHanoi(currentState)
      print()

      print("Subgoal:")
      printHanoi(subgoal)
      print()

    # find all possible states after h-steps
    future = lookHStepsAhead(currentState, horizon)

    selectedStateSimilarity = -1
    selectedNextState = []

    # analyze each possible state separately and find the state having largest
    # similarity value with the subgoal as the next state
    for item in future:
      similarity = calculateSimilarity(subgoal, item)
      if similarity > selectedStateSimilarity:
        selectedStateSimilarity = similarity
        selectedNextState = copy.deepcopy(item)

    # update the current state with the selected next state
    currentState = copy.deepcopy(selectedNextState)

    # check if the possible states are exactly same with the possible states of 
    # the two previous iterations and update the counter value accordingly
    if (previousFuture and sorted(previousFuture) == sorted(future)) or \
    (previousFuture and previousPreviousFuture and sorted(previousPreviousFuture) == sorted(previousFuture)) or \
    (previousPreviousFuture and sorted(previousPreviousFuture) == sorted(future)):
      counter += 1
    else:
      counter = 0

    # if the possible state lists remain unchanged for 10 consecutive iterations
    # Agent 1 decides that it cannot solve the puzzle and quits
    if counter == 10:
      if verbose:
        print("Cannot improve current state. Exiting.")

      break

    # save the states in the previousFuture variable into previousPreviousFuture
    # variable, then the recently processed states into previousFuture variable
    if previousFuture:
      previousPreviousFuture = copy.deepcopy(previousFuture)
    previousFuture = copy.deepcopy(future) 

  # stop stopwatch
  executionTime = time.time() - start

  return currentState, calculateSimilarity(mainGoal, currentState), executionTime

Simulations¶

In this section, I run the simulations and present the outcome.

I analyze the effect of horizon selection for different topologies. The number of disks and the number of pegs affect the performance. Increasing the number of disks make the solution more complex. On average, the horizon must get larger as the number of disks increases. Increasing the number of pegs loose the stress on finding the solution, yet, the execution time increases exponentially due to the expense of calculating h-steps in the future with higher number of possibilities.

Accordingly, I select 4 different topologies as given (in increasing time complexity) below:

T1) # of disks = 3, # of pegs = 3

T2) # of disks = 6, # of pegs = 3

T3) # of disks = 3, # of pegs = 6

T4) # of disks = 6, # of pegs = 6

Due to the increased execution time, the maximum h-value analyzed for each topology differs.

The simulation runs 30 different problems at each topology. All agents are provided with the same goal and the initial state. As a result, the differences between the agents are only based upon their algorithms.

Average execution times for each agent are also plotted as a separate figure.

To elicit a reliable comparison between the agents, I also provide statistical test results for each topology. For simplicity, I prefer non-parametric tests: Friedman's test for comparing the group differences between the similarity values of agents. It is followed by a post-hoc Wilcoxon signed rank test if the difference is significant.

def runSimulation(maxHValue):
  '''
  this method runs the simulations. it creates 30 different puzzles and executes
  Agents 0, 1, and 2, in respective order, for varying h-values. The h-value 
  begins from 1 and increases up to the value of 'maxHValue' parameter.
  @param maxHValue: indicates the largest value of h-value
  @return obtained similarity and execution time results  
  '''

  # create the empty matrices for storing the results
  similarityResults = [[[] for i in range(3)] for j in range(maxHValue)]
  executionTimeResults = [[[] for i in range(3)] for j in range(maxHValue)]
  initialSimilarities = []

  # pretty print information on running iteration number
  print('iteration #', " ".join([str(i) for i in range(1, 31)]))
  print('running     ', end="")

  # do the following for 30 times
  for iteration in range(30):
    
    # print a '.' for the running iteration
    if iteration < 9:
      print(".", end=" ")
    else:
      print(". ", end=" ")

    # create a random puzzle
    mainGoal = randomTower()
    initialState = randomState()

    # calculate the similarity of the initial state
    initialSimilarities.append(calculateSimilarity(mainGoal, initialState))

    # for each value between [1, maxHValue]
    # assign the value as the h-value
    for horizon in range(1, 1 + maxHValue):

      # execute Agents 0, 1, and 2, in order
      a0 = runAgent0(mainGoal, initialState, horizon)
      a1 = runAgent1(mainGoal, initialState, horizon)
      a2 = runAgent2(mainGoal, initialState, horizon)

      # store the results
      similarityResults[horizon-1][0].append(a0[1])
      similarityResults[horizon-1][1].append(a1[1])
      similarityResults[horizon-1][2].append(a2[1])
      executionTimeResults[horizon-1][0].append(a0[2])
      executionTimeResults[horizon-1][1].append(a1[2])
      executionTimeResults[horizon-1][2].append(a2[2])

  print('done!!')
  return similarityResults, executionTimeResults


def plotResults(values, maxHValue, ylabel):
  '''
  this method plots the provided results.
  @param values: similarity or execution time results returned from 
                 the runSimulation() method
  @param maxHValue: indicates the largest value of h-value
  @param ylabel: the label of the y-axis in the plot
  '''

  # create the tick items for the x-axis
  h_values = [h for h in range(1, 1 + maxHValue)]

  agent0_y = []
  agent1_y = []
  agent2_y = []

  # calculate average similarity of the agents for each h-value
  for h in range(maxHValue):
    agent0_y.append(sum(values[h][0]) / len(values[h][0]))
    agent1_y.append(sum(values[h][1]) / len(values[h][1]))
    agent2_y.append(sum(values[h][2]) / len(values[h][2]))

  # create an empty figure
  fig = plt.figure()

  # write tick values into the x-axis
  plt.xticks(h_values)

  # plot the values
  plt.plot(h_values, agent0_y, '+-', label='Agent 0')
  plt.plot(h_values, agent1_y, '*-', label='Agent 1')
  plt.plot(h_values, agent2_y, '.-', label='Agent 2')

  # update the labels of both axes
  plt.xlabel("h-values")
  plt.ylabel(ylabel)

  # add a legend and show the figure
  plt.legend()
  plt.show()  


def doStatisticalTests(values, maxHValue):
  '''
  applies statistical tests to the provided results.
  @param values: similarity results returned from the runSimulation() method
  @param maxHValue: indicates the largest value of h-value
  @return a table consisting of statistical test results
  '''

  result = []
  columns = ['\nh-value', 'Agent 0\nsimilarity', 'Agent 1\nsimilarity', 'Agent 2\nsimilarity', \
             '\nFriedman test', 'Wilcoxon test\nAgent 0 - Agent 1', \
             'Wilcoxon test\nAgent 0 - Agent 2', 'Wilcoxon test\nAgent 1 - Agent 2']

  for h in range(maxHValue):
    row = []
    row.append(h+1)

    # calculate average similarity of the agents for each h-value
    row.append(float("%f" % (sum(values[h][0]) / len(values[h][0]))))
    row.append(float("%f" % (sum(values[h][1]) / len(values[h][1]))))
    row.append(float("%f" % (sum(values[h][2]) / len(values[h][2]))))

    # apply Friedman test
    statistics, p_value = st.friedmanchisquare(values[h][0], values[h][1], values[h][2])

    # format the results with actual numbers only (omit NaN values) 
    if p_value < 1:
      row.append("X^2=%5.2f, p=%.3f" % (statistics, p_value))

      # if the group differences are statistically significant
      # then do pairwise comparisons
      if p_value < 0.05:
        t_value_0_1, p_value_0_1 = st.wilcoxon(values[h][0], values[h][1])
        t_value_0_2, p_value_0_2 = st.wilcoxon(values[h][0], values[h][2])
        t_value_1_2, p_value_1_2 = st.wilcoxon(values[h][1], values[h][2])

        row.append("W=%5.2f, p=%.3f" % (t_value_0_1, p_value_0_1))
        row.append("W=%5.2f, p=%.3f" % (t_value_0_2, p_value_0_2))
        row.append("W=%5.2f, p=%.3f" % (t_value_1_2, p_value_1_2))
      else:
        row.extend(["-"]*3)

    else:
      row.extend(["-"]*4)

    result.append(row)

  # tabulate data for pretty print
  return tabulate(result, headers=columns, tablefmt="presto", numalign='center', 
                  stralign='center', floatfmt=("2.2f", "1.2f", "1.2f", "1.2f"))

At this point, we need further analysis to investigate whether any of the methods perform significantly better than the others. Since there are more than two independent groups (more specifically 13), we cannot immediately apply pairwise comparison to the results. First, we need to check whether the differences between the group means are significant.

For comparing the differences of means between more than two independent groups, we can use the one-way ANOVA parametric test. One-way ANOVA is a strong test, but it relies on the below given assumptions:

  1. The samples are independent.
  2. Dependent variables are approximately normally distributed for each category of the independent variable. One-way ANOVA is robust to small violations of normality, i.e. assumption can be a little violated and still provide valid results.
  3. The population standard deviations of the groups are all equal. This property is known as homoscedasticity or homogeneity of variances.

The first assumption is valid for our data, since 60 participants per method were recruited. As a result, no participant in one group has data for another method; hence, samples are independent.

For the second assumption, we will use the Shapiro-Wilk test to check whether data for each method is normally distributed or not. A p-value less than 0.05 indicates that the data is NOT normally distributed.

Finally, for the third assumption, we will utilize Levene's test for equality of variances. A p-value less than 0.05 indicates that the variances of the methods are NOT equal and violates the third assumption.

If any of these assumptions are violated, we can use the non-parametric counterpart of the one-way ANOVA test, which is the Kruskal-Wallis H-test. Kruskal-Wallis H-test is not as strong as the one-way ANOVA test, yet, it provides reliable results when the mentioned assumptions are violated.

Now, let's use the Shapiro-Wilk test on each method separately to see if its data is normally distributed or not. In the output, normally distributed methods are printed in Green color. The Red color is used, otherwise.
